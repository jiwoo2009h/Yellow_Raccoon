# 자람 → Figma (오토레이아웃 디자인 만들기)

`plugin/` 폴더는 Figma 플러그인이에요. 실행하면 Figma 파일 안에 **자람 앱 화면 18개 × 라이트·다크 = 36개 프레임**을 만들어요. (홈·식물 상세·촬영·분석 결과·크기 보정·리포트·설정·기준·알고리즘·식물 등록·시트들·분석 영역·3D 측정 촬영·3D 결과·기준 제안·추천 효과 검증·로그인)

- **오토레이아웃**: 모든 카드·목록·버튼·입력칸이 가로/세로 오토레이아웃(간격·여백·정렬·FILL/HUG)으로 만들어져서, 글자를 고치면 크기와 배치가 저절로 맞춰져요.
- **색상 변수**: `자람 색상 · 라이트`, `자람 색상 · 다크` 변수 묶음이 생기고 (CSS 변수와 같은 이름: `bg`, `surface`, `text-1`, `accent` …) 프레임의 색이 여기에 연결돼요. 변수 값을 바꾸면 그 테마의 모든 화면이 함께 바뀌어요.
  - 무료(Starter) 요금제는 변수 모드를 1개만 쓸 수 있어서 테마별로 묶음을 나눴어요.
- **글꼴**: 컴퓨터에 [Pretendard](https://github.com/orioncactus/pretendard)가 설치돼 있으면 Pretendard, 없으면 Noto Sans KR 을 써요. Medium·SemiBold 같은 굵기도 그대로 들어가요.
- **반투명 흐림**: 상단바·탭바·사진 위 버튼에 배경 흐림(Background blur)이 들어가요.
- **전체 길이**: 스크롤되는 화면도 끝까지 한 프레임에 들어가고, 하단 탭바·버튼은 바닥에 고정돼요.
- 이 방식은 Figma MCP 호출 한도와 상관없이 몇 번이든 실행할 수 있어요.

## 실행하기 (Figma 데스크톱 앱 필요)

개발 중인 플러그인은 브라우저가 아닌 **Figma 데스크톱 앱**에서만 불러올 수 있어요. (https://www.figma.com/downloads/)

1. 데스크톱 앱에서 디자인 파일을 엽니다.
2. 메뉴 **Plugins → Development → Import plugin from manifest…** 를 누르고
   이 폴더의 `plugin/manifest.json` 을 고릅니다. (처음 한 번만)
3. **Plugins → Development → 자람 디자인 만들기** 를 누릅니다.
4. 30초 정도 지나면 **`자람 · 오토레이아웃`** 페이지가 생기고 화면이 만들어져요.
   윗줄이 라이트, 아랫줄이 다크예요.

다시 실행하면 그 페이지를 지우고 새로 만들어요 (변수 값은 갱신). 직접 고친 프레임이 있다면 다른 페이지로 옮겨 두세요.

## 레이어 이름 읽는 법

| 이름 | 뜻 |
|---|---|
| `card`, `list-item`, `btn` … | 앱 CSS 의 클래스 이름 (코드와 1:1로 찾을 수 있어요) |
| `spacer` | 간격이 일정하지 않은 곳에 넣은 투명한 빈칸 |
| `○○ 정렬` | 가운데·오른쪽 정렬을 위해 감싼 투명한 프레임 |
| `○○ 자리` | 상단바처럼 위에 겹쳐 놓인(절대 위치) 요소가 차지하는 빈자리 |
| `divider` | 목록 사이 구분선 |

## 앱 화면이 바뀌었을 때 다시 만들기

`plugin/code.js` 는 실제 앱 화면을 읽어서 자동으로 만든 파일이에요. 앱을 고친 뒤에는:

```bash
cd jaram
python seed_demo.py
JARAM_DATA=data-demo python app.py --port 5000      # 다른 터미널에서 켜 둠
npm i -D playwright && npx playwright install chromium
node design/figma/build.js http://127.0.0.1:5000
```

| 파일 | 하는 일 |
|---|---|
| `extract.js` | 브라우저 안에서 화면(DOM)을 읽어 프레임·텍스트·이미지·벡터 트리로 바꿈 |
| `build.js` | 라이트/다크 결과를 짝지어 색을 변수로 바꾸고, 간격·여백·FILL/HUG 를 계산해 `plugin/code.js` 생성 |
| `builder.js` | Figma 안에서 실행되는 플러그인 본체 (`code.js` 뒤쪽에 그대로 들어감) |

## 알아 둘 점

- 아이콘과 그래프는 벡터(SVG)로 들어가요. 그래프 글자는 Inter 글꼴이에요. 3D 미리보기(캔버스)는 읽은 순간의 그림이 이미지로 들어가요.
- 반복되는 부품(버튼, 배지, 목록 줄)을 Figma **컴포넌트**로 묶지는 않았어요. 필요하면 자주 쓰는 것부터 컴포넌트로 만들면 돼요.
- 데모 데이터로 만든 화면이라 식물 이름·수치는 예시예요.
